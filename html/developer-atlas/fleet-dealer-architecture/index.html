12 · COMMON SQL 01

모든 페이지가 먼저 호출하는 업체·그룹·차량 조회 범위

신규 표준계층 초기 이관

ORGANIZATION_RELATION

INSERT INTO ORGANIZATION_RELATION
(organization_id, equipment_id, relation_type,
 valid_from, valid_to, source_table, source_key)
SELECT ce.COMPANY_ID, ce.EQUIPMENT_ID, 'OPERATE',
       '2000-01-01', NULL, 'TB_COMPANY_EQUIPMENT',
       CONCAT(ce.COMPANY_ID, ':', ce.EQUIPMENT_ID)
  FROM TB_COMPANY_EQUIPMENT ce
 WHERE ce.PERMIT_YN = 'Y';
공통 범위 조회

백엔드 처리 기준

SELECT e.EQUIPMENT_ID, e.EQUIPMENT_NAME,
       e.GROUP_ID, e.FUEL_TYPE_CODE,
       e.TERMINAL_ID, e.LAST_WORKING_DATETIME
  FROM TB_EQUIPMENT e
  JOIN ORGANIZATION_RELATION r
    ON r.equipment_id = e.EQUIPMENT_ID
 WHERE r.organization_id = :companyId
   AND r.relation_type = :relationType
   AND :asOf >= r.valid_from
   AND (r.valid_to IS NULL OR :asOf < r.valid_to);
입력serviceType, userId, companyId, groupId?, equipmentId?, asOf서버 검증사용자 역할 → 업체 관계 → 차량 관계 순서출력scopeId, allowedCompanyIds, allowedEquipmentIds, permissions[]

전환기신규 관계 테이블 적재 전에는 TB_COMPANY_EQUIPMENT와 TB_EQUIPMENT의 DEALER_COMPANY_ID를 어댑터에서 병행 조회

13 · COMMON SQL 02

차량·배터리 에러를 한 목록으로 만들되 원천 유형은 보존

초기 적재 초안

FAULT_EVENT

INSERT INTO FAULT_EVENT
(source_type, source_seq, equipment_id, occurred_at,
 fault_type, error_code, spn, fmi, resolved_at)
SELECT 'EVENT_ERROR', SEQ, EQUIPMENT_ID, EVENT_DATETIME,
       'VEHICLE', BM_ERROR_CODE, LM_SPN, LM_FMI, RESOLVE_DATETIME
  FROM TB_EVENT_ERROR
UNION ALL
SELECT 'EVENT_LI_ERROR', SEQ, EQUIPMENT_ID, EVENT_DATETIME,
       'BATTERY', BM_ERROR_CODE, NULL, NULL, RESOLVE_DATETIME
  FROM TB_EVENT_LI_ERROR
UNION ALL
SELECT 'EVENT_BM_ERROR', SEQ, EQUIPMENT_ID, EVENT_DATETIME,
       'BATTERY', BM_ERROR_CODE, LM_SPN, LM_FMI, RESOLVE_DATETIME
  FROM TB_EVENT_BM_ERROR;
중복 방지·상태 변환

필수 규칙

  • UNIQUE(source_type, source_seq)로 재이관 중복 방지
  • 원천 RESOLVE_DATETIME은 완료 후보값일 뿐 업무 완료와 동일시하지 않음
  • 에러 구분은 faultType=VEHICLE|BATTERY로 응답
  • SPN/FMI가 없으면 null로 전달하고 문구를 임의 생성하지 않음
  • 코드 설명·조치·PDF는 코드 사전과 DOCUMENT_LINK에서 결합
출력 공통값faultId, faultType, errorCode, spn, fmi, occurredAt, resolvedAt, status, severity?, description?, document?

INSERT INTO SUPPLY_ACTION_HISTORY
(service_id, equipment_id, completed_at,
