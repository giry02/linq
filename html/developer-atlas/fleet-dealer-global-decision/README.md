# 플릿·딜러 글로벌 데이터 구조 및 구현안

- 실행: `index.html`
- 방향키 또는 하단 버튼으로 이동
- `O`: 전체 슬라이드 목록
- `P` 또는 `PDF`: 브라우저 인쇄/PDF 저장

## 문서 성격

현행 문제, 적용 방안, 목표 DDL, 공통 권한 SQL, 데이터 이관·검증 SQL, 페이지별 SQL과 프론트 API 계약을 하나의 흐름으로 통합한 회의·개발 문서입니다.

## 구성

- 현행 관계 구조와 국내·글로벌 문제
- 목표 구조 및 공통 조회 범위 적용 방안
- 이관·검증·롤백 쿼리
- 대시보드, 차량, 운행이력, 배터리, 서비스, 리포트·지도·관리 페이지별 SQL/API 계약
- 구현 전 반드시 결정할 업무 의미와 단계 전환 기준
