# MACHINE IQ 개발 아틀라스

현재 플릿·딜러 정적 프론트와 캡처 JSON을 기준으로 사용자·메뉴·화면·API·상태·요구사항을 연결한 검색형 HTML 문서입니다.

## 포함 범위

- 플릿(FL)·딜러(DL) 화면 ID 체계와 서비스별 화면 카드
- 대메뉴·소메뉴·사용 목적·주요 사용자·응답 데이터
- 15개 화면별 6단계 처리 흐름
- 화면별 FigJam 정확한 위치(node-id) 연결
- 플릿·딜러 조회 범위와 권한 차이
- 고객 PPT 요구사항 31건과 추가 의견 분리
- 핵심 결정·위험 6건
- 로컬 JSON 재생 계층을 개발 API로 교체하는 순서

## 프로세스 상세 사용법

1. 상단의 `플릿 화면` 또는 `딜러 화면`을 선택합니다.
2. 화면 카드의 `화면 흐름·FigJam 보기`를 누릅니다.
3. 팝업에서 사용자 진입부터 다음 이동까지 6단계를 확인합니다.
4. `FigJam에서 이 화면 위치 바로 보기`를 누르면 전체 보드가 아니라 해당 화면의 node-id 위치로 이동합니다.

## 제외 범위

현재 프론트 소스만으로 확인할 수 없는 DB 물리 모델, SAP·외부 시스템 내부 처리, 배치, 인증 서버 구현은 추정하지 않습니다.
