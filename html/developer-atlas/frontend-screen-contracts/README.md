# 프론트 화면별 변수·API 계약

- 목적: 플릿·딜러 각 화면이 받는 경로값, 조회조건, API 입력·출력 필드를 한 문서에서 확인
- 현행 근거: `html/final-implementation/fleet|dealer/assets/api*.js`, 캡처 JSON, QA 경로 목록
- 표현: 실제 확인된 값은 `현행`, 새 표준은 `개선안`으로 구분
- 실행: `index.html`을 열거나 정적 웹 서버에서 폴더 경로로 접근
- PDF: 우측 하단 `PDF` 버튼 선택 후 브라우저 인쇄에서 PDF 저장

응답 필드 타입은 캡처 JSON에서 확인된 실제 타입입니다. 캡처에 없던 요청 본문, 서버 내부 검증, DB 컬럼 타입은 확정값으로 표시하지 않습니다.
