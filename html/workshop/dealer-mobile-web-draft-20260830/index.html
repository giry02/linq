01 · DOCUMENT PURPOSE

검토 항목

권한확인·수정·완료 가능 범위

모바일웹의 역할

  • 판매·관리 대상 중 확인 필요 차량 우선 탐색
  • 차량 에러·배터리 에러 구분, 에러코드 안내·조치 자료 확인
  • 교체 대상 소모품 확인, 교체 완료일·조치사항 기록
  • 현재 미처리 항목 우선 표시, 완료 항목 별도 이력 보관
작성 범위
모바일 화면 디자인 제외. 메뉴·기능·권한·상태 기준 중심. 기준 확정 후 화면 설계 진행.

권장 메뉴 구조

에러긴급 문제 확인 및 조치차량 에러·배터리 에러 구분, 미처리 우선, 에러코드 안내, 매뉴얼 PDF, 처리 이력
소모품교체 권장 항목 확인 및 관리교체 대상 목록, 사용량·교체주기, 수정, 교체 완료, 완료일·조치사항 입력
설정계정과 알림 수신 기준 관리계정·로그아웃, 언어, 에러·소모품 알림 분리, 알림 허용 상태, 이용약관

04 · VEHICLES

차량 메뉴

단계기능표시 정보이동
목록차량 검색·상태 필터·정렬호기, 기종, 고객사, 연결상태, 에러·소모품 건수차량 상세
상세차량 기본정보와 현재 문제 요약동력유형, 소속, 누적시간·거리, 통신상태, 최종 통신일시에러, 소모품, 정비이력
위치최종 수신 위치 확인지도 위치, 최종 위치 수신일시지도 팝업
문제 확인차량의 문제를 유형별로 확인차량 에러, 배터리 에러, 소모품 교체 대상해당 상세 목록

데이터가 없을 때

값이 없는 항목의 undefined 표시 금지. “정보 없음”, “미수신”, “위치 미등록” 등 원인 구분.

08 · ROLE & DATA SCOPE

딜러 관리자소속 딜러 및 허용된 고객사·차량조회, 알림 설정, 소모품 완료, 직원 권한 관리 여부직원 관리 기능 포함 여부
