글로벌 확장 시
현재 구조의 문제와 개선 방향

플릿·딜러·업체·차량 관계를 고객 관점에서 쉽게 설명하고,
확장이 가능한 기준과 결정사항을 정리한 협의자료

01 · 핵심 결론

화면은 유지하고, 차량과 조직의 관계 기준만 하나로 정리

플릿과 딜러 화면을 합치거나 다시 만들 필요 없음

같은 차량을 누가 소유하고, 누가 운영하고, 누가 판매·정비하는지를
공통 기준으로 관리하면 국내 운영과 글로벌 확장을 함께 대응할 수 있습니다.

유지

현재 플릿·딜러 메뉴와 화면
운행·배터리·서비스 원천 데이터
현재 사용 중인 업무 흐름

보완

차량과 업체·딜러 관계
관계가 유효한 기간
사용자별 조회·처리 범위

기대 결과

화면별 차량 수 일치
잘못된 차량 노출 방지
국가별 기준 적용 가능

02 · 현재 구조

같은 차량 관계가 여러 위치에 나뉘어 기록

장비 기본정보

차량 기본정보 안에 현재 업체나 딜러 정보 포함

차량이 이동하면 기본정보 값도 함께 변경 필요

+

업체·차량 연결정보

별도 연결정보에서도 업체와 차량 관계 관리

화면마다 어느 정보를 기준으로 조회하는지 다를 수 있음

문제둘 중 한 곳만 변경되면 화면별 차량 수와 조회 권한이 달라질 수 있습니다.
03 · 관계의 의미

차량 한 대에도 서로 다른 관계가 동시에 존재

소유

차량의 계약상 보유 업체

자산·계약 기준

운영

현재 차량을 사용하는 업체

운행·위치 기준

판매

차량을 판매한 딜러

판매 이력 기준

정비

차량을 점검·수리하는 딜러

서비스 권한 기준
확인 필요업체 변경이 소유권 이전인지, 운영 업체 변경인지 구분하는 기준이 필요합니다.
04 · 현재 발생 가능한 문제

관계가 바뀌는 순간 화면과 권한의 차이가 발생

01

차량 양도

이전 업체 화면에 차량이 남거나 새 업체에 늦게 표시될 수 있음

02

운영 업체 변경

소유 업체와 실제 사용 업체가 다른 경우 조회 기준이 불명확

03

정비 딜러 변경

어느 딜러가 현재 에러와 정비정보를 처리할 수 있는지 판단 어려움

04

계약 종료

과거 이력은 보존해야 하지만 현재 화면에서는 제외해야 하는 기준 필요

05

화면별 집계 차이

대시보드, 차량목록, 서비스 화면의 차량 수가 달라질 수 있음

05 · 글로벌 확장 시 추가 기준

국가가 늘면 관계 외에도 공통 운영 기준 필요

국가·법인 경계

데이터와 사용자의 소속 기준

시간 기준

조회 일자와 알림 발생 시각

언어

메뉴, 오류 설명, PDF 제공 언어

단위

km/mile, L/gallon, ℃/℉ 표시

조직 계층

본사·법인·딜러·지점 구분

데이터 정책

국가별 보관 기간과 접근 범위

06 · 개선 원칙

기존 데이터와 화면은 유지하고 관계 기준을 공통화

1

원천정보 유지

운행, 배터리, 에러, 정비 데이터는 현재 구조를 사용합니다.

2

관계 이력 추가

소유·운영·판매·정비 관계와 적용 기간을 한 기준으로 기록합니다.

3

화면 공통 조회

플릿과 딜러가 같은 관계 기준으로 차량을 조회하도록 맞춥니다.

4

국가 기준 분리

언어·단위·시간·보관 정책은 국가별 설정으로 관리합니다.

07 · 목표 개념

조직과 차량 사이에 관계 종류와 유효기간을 기록

조직업체 · 딜러 · 지점
소유운영판매정비시작일 · 종료일
차량차대번호 · 모델 · 상태

현재 조회 종료일이 없거나 조회일에 유효한 관계

과거 이력 종료된 관계도 삭제하지 않고 기간으로 보존

동시 관계 허용 여부는 관계 종류별 정책으로 결정

08 · 변경 결과

업무 화면은 같고, 조회 결과의 일관성이 높아짐

구분현재개선 후
차량 수화면별 기준 차이 가능같은 관계 기준으로 집계
업체 변경현재 값 덮어쓰기변경일 기준으로 이력 보존
딜러 권한판매·정비 관계 구분 어려움관계 종류별 권한 적용
글로벌국가별 예외가 화면에 누적국가 설정으로 분리
운영 점검문제 발생 후 비교관계 불일치 사전 확인 가능
09 · 전환 단계

운영 중단 없이 단계적으로 전환

  1. 1단계

    기준 확정

    관계 종류, 기간, 권한, 국가 기준 결정

  2. 2단계

    현황 대조

    기존 업체·딜러·차량 연결값의 불일치 확인

  3. 3단계

    관계 이력 생성

    현재 값을 시작 관계로 옮기고 검증

  4. 4단계

    화면별 전환

    대시보드·차량·서비스 순서로 공통 기준 적용

  5. 5단계

    기존 값 정리

    안정화 후 중복 기준의 사용 중단

운영 원칙전환 기간에는 기존 결과와 새 결과를 함께 비교하여 차량 수와 권한을 확인합니다.
